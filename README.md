### ⭐ SmartSense — Predict. Rest. Recover.

> **Main Project · SIH 2026 Engineering Prototype**

<table>
<tr>
<td width="60%">

**SmartSense** is an AI-based multimodal wearable system for predictive driver drowsiness detection and intelligent alert/rest management — built for SIH 2026 problem statement PS 26220.

The system acquires physiological signals (EEG, EOG) via a **BioAmp EXG** sensor worn by the driver and transmitted wirelessly by an **ESP32** microcontroller. A **React 18 + TypeScript + Vite** dashboard processes the live feed, computes a vigilance score (0–100) through a rule-based Rest Decision Engine, and guides the driver through a six-stage safety loop: **DETECT → PREDICT → ALERT → REST → RECOVER → RESUME**.

Key capabilities include real GPS-based rest-stop recommendations (OpenStreetMap/Overpass, keyless), route-corridor trip planning with arrival deadlines, EEG sleep-phase monitoring during rest, a smart alarm, daily/weekly exportable reports, and a Supabase-backed multi-driver auth system.

### 🛡️ Crime Intelligence & Citizen Safety Platform

A Django-based web platform for crime complaint management and intelligence analysis.

Citizens can submit complaints with location data (latitude/longitude). Police officers and inspectors get dashboards for complaint review, case management, SOS alerts, missing-person reports, and lost-and-found tracking. An AI component (`ai_detector.py`, `priority_predictor.py`) uses **scikit-learn** to auto-prioritise incoming complaints. Crime **hotspot analysis** runs DBSCAN clustering on complaint coordinates (haversine distance) to identify High/Medium/Low risk zones on a map — no third-party mapping API required.

### 🎓 Scholar Sarthi — Scholarship & TNEA Counselling Aid

A full-stack **FastAPI + React + TypeScript** platform designed to help students navigate scholarship and engineering counselling workflows.

Applicants discover schemes, check eligibility, submit applications with supporting documents, and track status through a step-by-step wizard. An AI/document pipeline (PaddleOCR + LayoutLMv3) extracts and verifies uploaded documents, detects cross-document mismatches, and explains eligibility results in plain language. A deterministic rule engine handles eligibility decisions — AI assists, humans approve. Built as an engineering prototype for SIH 2026.

### 🧊 Industrial Refrigeration System — HMI Simulation

A Django-served frontend that simulates an industrial refrigeration unit as a BMS/HMI/SCADA operator screen.

The simulation runs entirely client-side using vanilla JavaScript. `simulation.js` maintains `machineState` and drives a fixed-interval tick loop — every sensor value (cabinet temperature, pressures, fan/compressor speeds) is derived from state, not random. Ten selectable faults map to equipment failures (compressor, evaporator fan, condenser, expansion valve, power) or warnings (door open, high temperature, high pressure, low airflow), with visual refrigerant-flow animation that tapers off smoothly during a compressor fault. An inline SVG machine mimic updates live state classes (`state-off / state-running / state-cooling / state-fault / state-warning`) on every tick.
